# Built-in Functions

Python has many built-in functions that can be used with different data types.

## Frequently Used Built-in Functions

* `len()` - returns the number of items.
* `type()` - tells the data type.
* `isinstance()` - checks whether a value belongs to a type.
* `sum()` - returns the total.
* `min()` / `max()` - returns the smallest or largest value.
* `abs()` - returns the positive value of a number.
* `round()` - rounds a number.
* `sorted()` - returns sorted values as a list.
* `enumerate()` - gives index and value together.
* `zip()` - combines multiple iterables.
* `range()` - generates a sequence of numbers.
* `any()` - returns `True` if at least one value is true.
* `all()` - returns `True` if all values are true.

## Example

```python
numbers = [10, 20, 30]

print(len(numbers))
print(sum(numbers))
print(max(numbers))
print(sorted(numbers))
```
